## 如何阅读

- 每个专题的 `README.md` 是阅读入口；系列内容按入门、原理和实战组织。
- 示例代码、配置和配图保留在所属专题中，跟随对应教程使用。
- 标注“草稿”或“待补充”的条目仍在整理，可以先阅读同分类下的其他内容。
